# VB-CABLE attribution and license

Historical attribution for the withdrawn 0.3.3 bundle. Current source no longer installs or routes audio through VB-CABLE. This page preserves the license information for existing copies; it is not a current setup recommendation. The reported antivirus detections have not been attributed to a specific component.

The optional Windows microphone uses the standard **VB-CABLE**, a separate,
closed-source donationware product by **VB-Audio / Vincent Burel**.
It is not part of DroidVideo's open-source code or MIT/GPL licenses.

Visit **https://vb-audio.com/Cable/** for the original product and to donate or
buy a license if you find it useful. Review the terms for professional use:
https://vb-audio.com/Services/licensing.htm

The unmodified standard Driver Pack 45 is included for convenient setup under
VB-Audio's standard VB-CABLE bundling terms. The original files and notices are
preserved. The A+B and C+D packages are not included.

DroidVideo names the standard cable's recording endpoint **DroidVideo Microphone**
and sends phone audio to its playback endpoint. Windows default devices are not
changed. Other applications using this same cable can share or interfere with
its audio; reserve it for DroidVideo while streaming.

Click **Set up microphone**, then **Install Driver** in the original VB-CABLE
window. Restart Windows if requested and click **Set up microphone** again.
Choose a phone microphone, start video, and enable DroidVideo Microphone.
Select **DroidVideo Microphone** as the input in your calling or recording app.
OBS's DroidVideo source receives phone audio directly and does not need VB-CABLE.

Remove the cable through its original setup program if you no longer need it.
