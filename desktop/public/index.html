First connection & installation
  1. USB: install Android Platform-Tools and enable USB debugging on your phone.
  2. Install the APK, open it, and allow camera and microphone access.
  3. Wi-Fi: enable sharing in the phone’s Wi-Fi menu and paste the pairing link here.
  4. While streaming, use Dim screen on the phone, then press its power button to turn off the display.

OBS & virtual camera

  1. Extract the Windows-Components ZIP into a permanent folder.
  2. Close OBS. Run Install-OBS.cmd as administrator, then restart OBS.
  3. Start video here. OBS → Sources → + → DroidVideo Camera + Audio. In properties, choose phone audio, a PC microphone, or no audio.
  4. For other camera apps: run Install-Camera.cmd as administrator. Enable virtual camera here, then select DroidVideo Camera in the other app.

Virtual camera carries video only; audio is delivered through the OBS plug-in. Keep the Windows app running. Rotate the OBS image using Transform if needed.

Wi-Fi/USB connects your phone and PC. OBS uses a local Windows pipe; no TCP address needs configuring.
